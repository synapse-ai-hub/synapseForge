synapseForge — Creador de skills
Una skill es un conjunto de instrucciones que el asistente usa para resolver una tarea específica. Es como un manual de experto: le dice cómo pensar, qué pasos seguir y qué tener en cuenta.

Solo minúsculas, números y guiones. Sin espacios ni mayúsculas.

Podés adjuntar archivos .md, .txt, .json, .csv, .yaml o .xml como material de referencia para la skill.
